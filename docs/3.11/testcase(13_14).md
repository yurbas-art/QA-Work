1. Переход на страницу погоды из виджета «Погода во Владивостоке»
Приоритет: Medium

Шаги:

1. Открыть главную страницу https://vl.ru
2. Найти в шапке/боковой панели блок «Погода во Владивостоке» (температура, ветер, облачность) 
3. Запомнить показанную температуру
4. Кликнуть по заголовку блока или по температуре
5. Дождаться загрузки страницы

Ожидаемый результат: Открывается страница погоды во Владивостоке с прогнозом, данные 
(температура, ветер) отображаются и не противоречат виджету на главной, ошибок нет

Фактический результат: Совпадает с ожидаемым результатом. Виджет на главной отображает 
температуру и ветер; клик по блоку ведёт на страницу https://www.vl.ru/weather, где отображается
текущая погода (температура, ветер, облачность) и прогноз на 10 дней; расхождений с виджетом не выявлено, ошибок нет 

2. Переход на страницу курсов валют из виджета «Деньги по курсу ЦБ»
Приоритет: Medium

Шаги:

1. Открыть главную страницу https://vl.ru
2. Найти блок «Деньги по курсу ЦБ» (курсы USD и EUR)
3. Запомнить значения курсов
4. Кликнуть по заголовку блока
5. Дождаться загрузки страницы

Ожидаемый результат: Открывается страница с курсами валют, значения USD и EUR соответствуют виджету на главной (с учётом даты), ошибок нет

Фактический результат: Совпадает с ожидаемым результатом. Виджет на главной отображает 
актуальные курсы USD и EUR ЦБ РФ; клик по заголовку ведёт на страницу курсов валют (https://www.vl.ru/dengi/currency/),
где значения USD и EUR соответствуют виджету с учётом даты; ошибок нет
