## 1. Открытие главной страницы

- **Приоритет:** High
- **Шаги:**
  1. Открыть браузер
  2. Ввести в адресной строке https://vl.ru
  3. Нажать Enter
  4. Дождаться полной загрузки
- **Ожидаемый результат:** Страница загружается без ошибок, отображаются шапка, меню, лента новостей, футер; изображения не «битые»
- **Фактический результат:** Совпадает с ожидаемым результатом

## 2. Переход по пунктам главного меню

- **Приоритет:** High
- **Шаги:**
  1. Навести курсор на пункт главного меню (напр. «Новости»)
  2. Кликнуть по пункту
  3. Вернуться на главную
  4. Повторить для остальных пунктов меню
- **Ожидаемый результат:** Каждый пункт открывает соответствующий раздел, URL и заголовок страницы соответствуют выбранному разделу, нет ошибок 404/500
- **Фактический результат:** Совпадает с ожидаемым результатом
