## 🛠️ Используемые технологии

- **Playwright** – это современный open-source фреймворк от Microsoft для автоматизации тестирования веб-приложенийфреймворк для端到端 (E2E) тестирования.
- **JavaScript / TypeScript** – язык написания тестов.
- **Git & GitHub** – система контроля версий и хостинг кода.
- **Postman** - инструмент для разработки и тестирование API
