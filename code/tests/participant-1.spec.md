Участник №1(Юрий). Главная страница ИТМО
3 сценария
Сценарий 1. Проверка загрузки главной страницы
- Что проверяем: главная страница открывается, отображается название университета.
- Зачем автоматизировать: главная страница — точка входа для пользователей. Ошибка загрузки или отсутствие основного заголовка критичны.
- Ожидаемый результат: страница открылась, заголовок присутствует.
Сценарий 2. Проверка перехода в раздел для абитуриентов
- Что проверяем: ссылка «Абитуриентам» ведёт на сайт приёмной комиссии.
- Зачем автоматизировать: это один из основных пользовательских маршрутов.
- Ожидаемый результат: пользователь попадает на abit.itmo.ru.
Сценарий 3. Проверка наличия раздела образования
- Что проверяем: на главной странице отображается блок «Образование».
- Зачем автоматизировать: образовательная информация — одна из основных функций сайта университета.
- Ожидаемый результат: блок доступен пользователю.
