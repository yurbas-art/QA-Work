Участник №1 — Главная страница
Сценарий 1. Загрузка главной страницы
- Что проверяет: Главная страница ИТМО открывается и отображает заголовок университета.
- Почему важно: Главная страница — основная точка входа. Её недоступность критична для пользователей.
- Шаги: 1. Открыть браузер. 2. Перейти на itmo.ru/ru/. 3. Проверить заголовок вкладки. 4. Проверить основной заголовок.
- Ожидаемый результат: Страница загружается, заголовок отображается.
- Как проверено: expect(page).toHaveTitle() и expect(locator).toBeVisible(). Локатор getByRole().
- Результат прогона: Заполнить после запуска теста.
